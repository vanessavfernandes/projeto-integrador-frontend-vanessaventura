# projeto-integrador-frontend-vanessaventura
Este projeto baseia-se em um catálogo digital, com o intuito de expor os produtos de quadros decorativos e placas personalizadas em MDF. 
O objetivo deste projeto é apresentar um portfólio de forma organizada por categorias, permitindo que os clientes consigam visualizar a descrição de cada produto.
Contudo, esta aplicação resolve a dificuldade de centralizar o mostruário de peças sob medida, agilizando o atendimento inicial e a solicitação de orçamentos online.
